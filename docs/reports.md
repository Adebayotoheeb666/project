# Reports & Broadsheets Specification

LSIA produces master broadsheets and termly student report cards directly on the school computer.

## Class Broadsheets

The broadsheet is a master matrix evaluating all students in a class across all subjects for a specific term:
- Calculates subject averages, highest score, lowest score, and student subject rankings (1st, 2nd, etc.).
- Computes each student's total marks, average score, and class position deterministically.
- Handles ties deterministically.

## Student Report Cards

Comprehensive academic and character evaluation for individual students:
- Student metadata (Name, Admission Number, Class, Academic Year, Term).
- Subject performance table (CA, Exam, Total Score, Grade, Remark, Subject Position, Class Average).
- Overall academic summary (Total Marks, Average, Class Position out of total students).
- Attendance statistics (Total school days, days present, attendance percentage).
- Performance-based teacher and principal comments generated from configurable templates.
- Ready for preview and one-click PDF printing.
